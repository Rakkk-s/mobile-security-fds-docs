# 단말 데이터

단말 보안 모듈이 관측한 정보로, 네 범주로 나뉜다. FDS 룰은 이 단말 데이터와 [금융 데이터](detection-financial.md)를 단말 식별값·거래 요청 시각으로 맞춰 결합해 판단한다. 각 데이터를 룰에서 어떻게 쓰는지는 [룰 정의서](rule-catalog.md)에서 다룬다.

| 범주 | 무엇을 보는가 | 개수 |
| --- | --- | ---: |
| 백신 (악성 앱 탐지) | 단말에 악성코드가 감염돼 있는지 | 13 |
| 단말 취약 여부 | 단말 무결성이 훼손됐거나 원격 연결 상태인지 | 11 |
| 단말 위협 (설치·실행) | 위협 앱이 깔려 있는지, 그 기능이 실제로 실행 중인지 | 42 |
| 단말 정보 | 단말의 식별값·위치·통신망·상태 | 18 |
| **합계** | | **84** |
