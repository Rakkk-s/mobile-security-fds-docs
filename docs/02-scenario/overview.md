## 3. 시나리오 작성 규격

모든 시나리오 페이지는 다음 구조를 따릅니다.

| 절 | 내용 |
| --- | --- |
| 1. 시나리오 설명 | 무엇이 일어나는지 한 문단으로 요약 |
| 2. 공격 흐름 | 번호가 매겨진 단계별 서술 + 다이어그램 |
| 3. 피해자의 인식과 실제 동작 | 두 열 대조표 |
| 4. 사용된 공격 기법 | 기법명과 사용 방식 |
| 5. 사용된 악성 앱 구조·기능 | 단일 앱인지 다단계인지, 어떤 유형인지 |
| 6. 단계별 탐지 지점 | 각 단계에서 관측 가능한 탐지 데이터 |
| 7. 적용 룰 | 이 시나리오를 방어하는 룰 목록 |
